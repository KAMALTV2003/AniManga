# Competitive Analysis

The canonical, dated research report is [research/competitive-analysis.md](research/competitive-analysis.md).

## Executive conclusion

ECC's strongest advantages are real harness integration, broad useful workflows, cross-harness adaptation, progressive context practices, security tooling, tests, and developer ergonomics. Native Claude Skills add an efficient progressive-disclosure model; MCP adds interoperability; graph and durable workflow systems add explicit state and recovery.

NEXUS should not compete on Skill count. Its defensible target is an evidence-connected capability control plane:

- mandatory transitive provenance;
- trust-first discovery and quarantine;
- semantic deduplication and behavior-level synthesis;
- capability graph composition of the smallest sufficient bundle;
- evaluation-gated learning, promotion, regression protection, and rollback;
- policy and sandbox enforcement outside prompts;
- measured model routing;
- conformance-tested cross-harness adapters;
- reproducible cost/quality/security benchmarks.

No ECC implementation code or untrusted Skill was imported during research.
